Project Overview & Architecture

End-to-end clinical risk prediction system built with production-grade engineering principles.

PROBLEM

Complex Multi-Parameter Clinical Diagnosis

Healthcare datasets contain diverse clinical parameters spanning biochemical markers, metabolic labs, and physiological vitals that can be complex to synthesize manually in fast-paced clinical or triage settings.

SOLUTION

Unified Multi-Disease ML Interface

This project provides a single, intuitive web interface connected to four independent machine-learning classification pipelines, each calibrated with disease-specific data cleaning and preprocessing.

System Scope & Known Limitations

  • Dataset Scale: Datasets range from 303 to 768 patient records; while clinically valid, broader multi-center cohorts enhance generalization.
  • Educational Scope: The models identify statistical correlations within training distributions and are not validated for standalone clinical diagnosis.
  • No Longitudinal Data: Predictions reflect cross-sectional snapshot values rather than multi-visit trajectory analysis.

Technology Stack

Engineered with lightweight, reliable, and production-ready tools.

Frontend

Client Interface

  • HTML5: Semantic and accessible structure
  • CSS3: Custom responsive design system with fluid typography and dark accents
  • Vanilla JavaScript: Asynchronous fetch requests, dynamic DOM rendering, client-side validation
Backend

Server & API

  • Python 3.11: Core backend programming language
  • Flask 3.1: Lightweight WSGI application framework
  • REST API: Validated endpoints for predictions, health check, and metadata
Machine Learning

Data & Modeling

  • Scikit-Learn: Random Forest and Logistic Regression classifiers
  • Pandas & NumPy: Data ingestion, cleaning, and array manipulation
  • Joblib: Model serialization and persistent pipeline loading
Deployment

Infrastructure

  • Gunicorn: Production WSGI HTTP server
  • Procfile: Standard web service specification
  • Render Ready: Configured for zero-config PaaS cloud hosting
